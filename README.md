# Notes API (NestJS)

A RESTful API for managing notes, built with [NestJS](https://nestjs.com/).

## Prerequisites

- Node.js (v18+)
- pnpm (or npm/yarn)

## Installation

```bash
$ pnpm install
```

## Running the app

```bash
# development
$ pnpm run start

# watch mode
$ pnpm run start:dev

# production mode
$ pnpm run start:prod
```

## Test

```bash
# unit tests
$ pnpm run test

# e2e tests
$ pnpm run test:e2e

# test coverage
$ pnpm run test:cov
```
